# Checklist de Execucao Diaria

Lista de verificacao para cada sessao de trading.

## Diario

- [ ] Ver tokens trending 24h (Dexscreener / Axiom)
- [ ] Pegar top 3-5 traders de cada token
- [ ] Analisar carteiras no GMGN (PnL, Win Rate, phishing)
- [ ] Aplicar Selecao Pesada (todos os criterios obrigatorios)
- [ ] Atualizar planilha de carteiras
- [ ] Configurar/revisar alertas de compra (BullX / Cielo)
- [ ] Revisar tweets de catalisadores (J7 Tracker)

## Pre-Entrada

- [ ] Phishing Check verde
- [ ] Liquidez suficiente
- [ ] Taxa de venda razoavel (inferior a 10%)
- [ ] Win Rate 30D superior a 50%
- [ ] PnL 30D superior a +$10.000
- [ ] Pelo menos 20 trades em 30D
- [ ] Nao concentra mais de 40% do lucro em 1 token
- [ ] Stop-loss definido
- [ ] Posicao representa menos de 5% do capital total
- [ ] Nao e revenge trading

## Semanal

- [ ] Revisar performance de todas as carteiras da planilha
- [ ] Atualizar PnL e Win Rate de todas as carteiras
- [ ] Descartar carteiras que performaram mal
- [ ] Revisar aprendizados e padroes de sucesso/falha
