## Notas para App Review

```
Papel is a 100% offline PDF reader. It does NOT collect any user data,
make network connections, use analytics, or track users.

FILE ACCESS:
The app uses UIDocumentPickerViewController to let users choose
PDF files explicitly. It does not access files without user action.
No MANAGE_EXTERNAL_STORAGE or broad file system access is requested.

PERMISSIONS:
- File access: Only through the system file picker (user-initiated)
- No camera, microphone, location, contacts, or network permissions

PRIVACY MANIFEST:
- NSPrivacyTracking: false
- No tracking domains
- No collected data types
- Required Reason APIs: file timestamp (DDA9.1) for displaying
  file modification dates to the user

The app is a free, offline-only tool with no in-app purchases,
no subscriptions, no ads, and no data collection of any kind.

Demo: The app opens directly to a file picker. Users select a PDF,
which opens in the reader with filter and navigation controls.
No login, no setup, no internet connection needed.
```

## App Store Optimizer (ASO) — Dicas

### Palavras-chave Estratégicas
1. **pdf reader** — busca alta, alta concorrência
2. **leitor de pdf** — busca moderada no Brasil
3. **filtros de tela** — nicho, baixa concorrência
4. **leitura offline** — diferencial competitivo
5. **proteção ocular** — nicho de saúde digital

### Otimização
- Nome contém as palavras-chave mais importantes
- Subtítulo complementa com diferencial (filtros)
- Primeira screenshot deve mostrar o app abrindo um PDF
- Descrição usa bullets para facilitar escaneamento
- Keywords não repetem palavras do nome/subtítulo
